ICalSync

Seamlessly Sync Calendars, No More Meeting Mix-ups!

Sync multiple external calendars into Google Calendar in realtime, from any iCal (.ics) feed.

Install from the Marketplace Setup guide

Many calendars, one view

Point ICalSync at any external iCal feed — a client's calendar, a booking system, a university timetable — and it lands in Google Calendar alongside everything else.

Realtime, not nightly

Changes on the source calendar follow through as they happen, so the version you are looking at is the version everyone else is looking at.

No more mix-ups

Double bookings and missed events come from calendars that never talk to each other. This one makes them talk.

Get started

Up and running in minutes

01

Install from the Marketplace

Open the listing, choose Install and grant the calendar permissions the app explains up front.

02

Questions

Before you install

Which calendars can I connect?

Anything that publishes a standard iCal (.ics) feed — most booking systems, university timetables, project tools and other calendar providers do.

How quickly do changes appear?

Updates on the source calendar follow through in realtime rather than on a nightly batch.

Can my whole organisation use it?

Yes. A Google Workspace administrator can install ICalSync domain-wide from the Marketplace.

What happens if I uninstall?

Access is revoked immediately from the Marketplace or your Google account's connected apps.
